# Mars phase

Same approach as the Moon phase, kept in its own folder so Moon and Mars data are never mixed.

Targets: four Mars exploration sites, Jezero, Oxia Planum, Gale and Meridiani. Mars terrain comes from the USGS HRSC+MOLA 200 m global DEM; thermal inertia and albedo from NASA PDS / TES mosaics.
Search pool: arid land worldwide (WorldClim screen), 30 km blocks at 200 m from the Copernicus DEM.
Categories: terrain, geology (Macrostrat), albedo, diurnal swing, dryness, vegetation, pressure, cold; then Landsat/Sentinel-2 verification and a literature check.

Raw data is not stored here. Start with `MARS_FINDINGS.md` and `results/mars_final_table.csv`.
